# keisetsu-tools

『螢雪時代』連載「小船幹生の Study Hack」付録の、動く教材ギャラリー。

- `english/` … 英語10種（語順/時制/冠詞/前置詞/関係詞/5文型/動詞型/レジスター/誤り診断/三角ロジック）
- `stem/` … 数学3種・物理3種（単位円/二次関数/微分・斜方投射/波の重ね合わせ/電磁誘導）
- `kakomon/` … 過去問1問から理解を確かめる（11月号・数学。2024年東大 数学（理科）第5問の回転体を切って回して確かめ、答案への問い返しをAIに頼む依頼文をコピー）
- `machigai/` … 誤り探しトレーナー（10月号・地理と数学。雨温図の誤り3か所/ずれ始めの行あて/自分であえて間違えてAIに見せる）
