三角ロジック・トレーナー

自由英作文は、三角ロジックで組む

和文英訳ではなく、主張 → 根拠 → 論拠 → 回帰という三角の型で段落を設計します。テーマとレトリック（合図ことば）を選ぶと、色分けされた英文と三角形の図で、論理の運びが見えます。

① テーマと② 展開（レトリック）を選ぶと、右に色分けされた英文の段落と、Claim–Data–Warrant の三角形が組み上がります。色＝論理の役割です。

① テーマを選ぶ（自由英作文の頻出）
② 展開（レトリック）を選ぶ
色＝論理の役割 主張 Claim 根拠 Data 論拠 Warrant 回帰 →主張
この展開のねらい
6つのレトリック（合図ことば）

「②根拠」を主張へつなぐ運び方です。同じ主張でも、選ぶレトリックで説得の形が変わります。

例示
For example / For instance
具体例で主張を裏づける
因果
because / therefore / as a result
理由・結果でつなぐ
比較
while / compared with / whereas
二つを比べて際立たせる
時系列
First … Then … Finally
順を追って展開する
提案
should / it would be better to
提案・助言で締める
反例→再反論
Some may argue … However … / Admittedly … but …
反論を受けて切り返す
気づき
自由英作文は、思いついた文を並べる作業ではありません。主張 → 根拠 → 論拠 → 回帰（主張へ）という三角で組み、根拠を支えるレトリック（例示・因果・比較・時系列・提案・反例）を選ぶと、説得力があって最後に“落ちる”段落になります。
