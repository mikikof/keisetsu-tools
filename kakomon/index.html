三角形を回すと、どんな立体になる？

2024年 東京大学 · 数学（理科）第5問

A(1, 0, 0)、B(0, 1, 0)、C(0, 0, 1)をとり、DをACの中点とする。三角形ABDの周と内部をx軸のまわりに１回転させた立体の体積を求める。

出典：東京大学公表の問題（12ページ） · 条件を整理して表記。図と解説は本教材で作成。体積計算は数学III。

元の問題・x＝1/5・回転角0°に戻し、最も近い点Mを表示します。

xは切断する平面の位置です。灰色はその平面の一部を示しています。回転中も、動いた点には回転前と同じ記号を付けています（Cと破線AC・BCは回転前の位置）。同じ点に重なる記号は「D = F」のようにまとめます。x = 0では切り口が点Bとなり、回転すると円周に、x = 1では回転軸上の点Aになります。

考えたあとに、元の問題の解答と場合分けを確認する

平面 x = t で切ると、三角形の切り口は線分EFになる。Eは辺AB上、Fは t ≤ 1/2 では辺BD上、t ≥ 1/2 では辺AD上にある。

回転前の切り口では y + z = 1 − t。軸に最も近い点は、垂線の足が線分上にあればその足、線分の外にあれば端点Fになる。

外半径 R = 1 − t
内半径の２乗 r² =
1 − 4t + 5t²　（0 ≤ t ≤ 1/3）
(1 − t)² / 2　（1/3 ≤ t ≤ 1）

t = 1/2 でFがある辺は変わるが、内半径を求める式は変わらない。内半径の式を分ける境目は、垂線の足が線分に入る t = 1/3 である。

S(t) = π(R² − r²) =
π(2t − 4t²)　（0 ≤ t ≤ 1/3）
π(1 − t)² / 2　（1/3 ≤ t ≤ 1）

STUDY HACK 2

条件を一つ変えて、理解を確かめる

確認A · 同じ問題で判断を確かめる

「1/2で分ければ十分」と言える？

元の問題で、x = 1/5 と x = 2/5 の断面を描き、軸に最も近い点をそれぞれ示そう。同じ辺AB・BDで切られているのに、何が変わっているだろう。

考えたあとに確認する

x = 1/5では端点F、x = 2/5では線分の途中にある垂線の足が最近点。境目は x = 1/3。「端点がどの辺にあるか」の場合分けだけでは、内半径を決められません。

確認B · 点Dの位置を変える / 本教材の追加問題

Dを、ACを1 : 2に内分する点に変えると？

AD : DC = 1 : 2、すなわちD(2/3, 0, 1/3)に変更する。他の条件は同じ。内半径を求める式の境目は、x = いくつになるだろう。

考えたあとに確認する

境目は x = 1/2。平面 x = t で切ると考えます。FがBD上にあるとき、切断面の線分上では 0 ≤ z ≤ t/2。垂線の足の z 座標は (1 − t)/2 なので、(1 − t)/2 ≤ t/2 から t ≥ 1/2 です。FがAD上へ移る境目の2/3とは異なります。

条件の変更は上の２枚の図に反映されます。答案の確認と体積の解説は、DがACの中点である元の問題が対象です。
