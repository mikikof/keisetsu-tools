二次関数モーフ

係数 a・b・c を動かすと、放物線が変わる

y = ax² + bx + c の3つの係数をスライダーで変えると、放物線・頂点・軸・x軸との交点がその場で動きます。とくに判別式 D = b²−4ac の符号が、x軸と交わる点の数を決めます。

気づき
a は放物線の開きと向き（+ で下に凸／− で上に凸）。頂点は必ず ( −b/2a , c−b²/4a ) にあり、その真上を通る縦線が軸 x = −b/2a。そして判別式 D = b²−4ac の符号が、x軸と交わる点の数を決めます — D>0 なら2点、D=0 なら接して1点（重解）、D<0 なら交わらない。動かすと「D が 0 をまたぐ瞬間に、交点が生まれる／消える」のが目で見えます。
